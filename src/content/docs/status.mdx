## What each check means

- **app.picstome.com** is the panel you use to upload galleries, send contracts and invoice. If this is down, nothing works.
- **picstome.com** is the public website: the marketing pages, the download links and the help center. A failure here does not stop your galleries from working.

The board refreshes its data every minute on the server that renders this page. UptimeRobot itself checks the services every 5 minutes on the free plan, so a very short outage can appear here a few minutes late.

## If one of them is red

1. Open the affected site in a private window to rule out a cached session or an extension.
2. Check that you are not behind a blocked network or VPN.
3. Wait 5 minutes and reload this page: the status is refreshed automatically.
4. If it is still red, open an issue in [GitHub](https://github.com/picstome/picstome/issues) with the time and the exact URL.

## If both are green and you still cannot work

The status page only tells you whether the servers answer. For a single gallery, contract or invoice that does not load, the answer is usually in the article of that section: use the search or the **?** button inside the panel.
