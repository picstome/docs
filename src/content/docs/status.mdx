## What each check means

- **app.picstome.com** is the panel where you upload galleries, send contracts and invoice. If this is down, nothing works.
- **picstome.com** is the public website: the product pages, the download links and this help center. A failure here does not stop your galleries from working.

## If one of them is red

1. Open the affected site in a private window to rule out a cached session or an extension.
2. Check that you are not behind a blocked network or a VPN.
3. Wait a few minutes and reload this page.
4. If it is still red, [contact us](/support/) with screenshots, the exact time and the URL you were opening.

## If both are green and you still cannot work

The status page only tells you whether the servers answer. If a single gallery, contract or invoice does not load, the answer is usually in the article of that section: use the search or the **?** button inside the panel.

If you cannot find it, [contact us](/support/): we answer every message.
